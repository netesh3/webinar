Rules that keep it unconfusing
  • One layout. Same size and frame, the picture on top, and the bar below with LIVE, what you're sharing, the time, and Back to webinar.
  • One label decides. A green dot with "Live view" means it moves. A pause icon with "Snapshot · not updating" means it doesn't. Nothing else differs between A and B.
  • The bar's LIVE badge always means "you are sharing". It is never used to describe the preview.
  • The stage follows the same rule. The stage and the floating window always show the same kind of picture: both live or both snapshot.
