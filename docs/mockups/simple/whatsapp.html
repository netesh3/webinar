WhatsApp. Today: 3 tabs; the same template editor twice (Templates and Number & billing); starter / approved / picker lists of the same templates; "Fill {{2}} with", "en · utility"; a 5-step checklist that stays after it's done; 9 automation cards. Here: one page. A one-line connection status (the checklist only shows until it's done). The three messages attendees get, shown as they read them, each with "Change" — which opens the message picker in plain words, the phone preview and "Send me a test"; the blanks are filled automatically. Automations are rules written as sentences — "When … → …" — with switches; "+ New automation" builds your own from plain choices (answers a poll, comes / misses, engagement group, taps a button, replies with a word, gets a tag → wait, send, tag, tell me), and says how many it would have reached. The old recipes, sequences and bots become these rules; a one-off broadcast is "Send a message now". The three messages everyone gets stay fixed (they follow the webinar's timeline), each editable.
