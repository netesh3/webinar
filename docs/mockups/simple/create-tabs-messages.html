Tab 2 · Messages & follow-ups, cleaner. No bar of global settings on top — straight to a list: one line per message, grouped Before · After, every row built the same: timing, the channels it goes by, an on/off switch and an arrow. Click one and the pane on the right sets how it goes — Send this by: Email, WhatsApp (tick one or both) — and the phone shows it as the attendee reads it — this webinar's title and time filled in; everything is changed right in the pane (no separate Edit); switch between the WhatsApp and email versions. Each message sets its own channels there. Shown with Reminder selected: its times live in its pane too — When: 1 day before, 1 hour before, + Add a time. Each message also picks its own wording under Message — a few WhatsApp-approved options for that use case (or write your own, see all), just for this webinar unless “Use this for all my webinars” is ticked. Every message has the same switch — turn any of them off for this webinar (Replay is off here). Click anywhere on a row except its switch to open it in the pane on the right. Follow-ups that aren't set up sit dimmed at the bottom of After (“Not set up” — open one to set it up). The When → Then automations that also run for this webinar are listed with their switches, plus New automation and a link to all of them on the WhatsApp page. No previews repeated six times.
