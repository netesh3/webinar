Engage v1, inside Hosting

No new menu. Two new tabs on the Hosting home (People, Messages), plus additions on each webinar page. Same tokens and primitives as web/components/ui.tsx. Spec: docs/engage/V1.md.

Where each step lives
  1. Hosting → People: everyone across all webinars; filter, tick, message.
  2. Hosting → Messages: one inbox for replies from every webinar; the bell and webinar cards link here.
  3. Upcoming webinar → Messages: confirmation, 24 h and 1 h reminders.
  4. Ended webinar → Attendees (existing tab, now with watch time and messaging): filter by watch time, tick rows, message them.
  5. Ended webinar → Messages: what was sent for that webinar, with read counts.
  6. Account → WhatsApp: connect the Business app number so replies also work from the phone.
