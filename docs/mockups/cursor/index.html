Engage — WhatsApp automation & CRM

Seventeen screens for the WhatsApp module inside Webinar Liv: the shared inbox, contacts, journeys, broadcasts, templates, analytics and the Meta connection. Every screen is built from one stylesheet and one shell, so the chrome, the icon set and the numbers agree across the whole set.

17 screens 1 stylesheet, 1 shell script No CDN — works offline Hand-drawn SVG icon set Open the demo
Why a rebuild rather than the Stitch exports. The fifteen Stitch screens in source/ were generated independently, so they disagreed with each other: two different sidebars, two different product names (Engage and WebinarLiv), three different audience sizes for the same workspace and three different messaging tiers. They are kept for reference, and every number here was reconciled against them — see the canonical dataset.

The 24-hour window

The one constraint every WhatsApp product is built around, and the reason the Templates screen exists. A contact’s reply opens a 24-hour service window; inside it, replies are free-form and free of charge. Outside it, only an approved template can reopen the conversation, and Meta bills that as business-initiated. The inbox shows both states, because a composer that is merely greyed out never explains why.

The broadcast wizard, layer by layer

A dialog that only ever shows one step is the least honest thing a mockup can do, because the steps either side are the part being designed. All five are real and the rail navigates between them. Each also has its own address — ?step=4 — so a single layer can be linked to or reviewed on its own.

Notes

  • A screen file holds only its <main class="page">. The sidebar, topbar and switcher are injected, so the nav changes in one place.
  • No Tailwind, no icon font, no web font request. The Stitch originals go unstyled without a network; these do not.
  • Controls that cannot really work say so in a toast rather than dead-ending on href="#".
  • The broadcast wizard is five real layers, not one frozen step. The rail navigates, and ?step=4 opens a layer directly.
  • Rebuild the thumbnails with python3 scripts/render.py.
