# Mobile join smoke checklist (real iPhone)

Use a physical iPhone (Safari), not the simulator.

1. Join a CDN/HLS webinar while muted autoplay is allowed — video should start without a tap; tap **Click to Unmute** for audio.
2. Watch for at least five minutes.
3. Background Safari (home screen or another app) for 20+ seconds, then return — playback should resume.
4. Raise hand with one thumb; open Q&A from the standing bar.
5. Host sends a promote-to-stage invite — **Stay as attendee** keeps HLS; **Join stage** remounts WebRTC. Demote returns to HLS.
6. Host launches a CTA overlay — the card is reachable above the control bar.
